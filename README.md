# Метро Москвы

Небольшой проект для поиска маршрутов по части московского метро

В метрополитене есть 31 станция.  Станции являются вершинами, а переходы между ними - ребра.
Вес ребра показывает примерное время поездки или перехода в минутах

Для поиска кратчайшего пути используется алгоритм дейкстры

## Структура проекта

- `graph.py` — класс графа(исключения и алгоритм дейкстры)
- `metro.py` — станции, перегоны, переходы и время
- `main.py` — работа с остальными файлами и вывод результата

## Запуск

Все команды нужно запускать из папки проекта

Найти кратчайший путь:

```bash
python -m main path --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
```

Программа выведет станции маршрута по одной на строку

Показать только время:

```bash
python -m main time --from "Арбатская (Арбатско-Покровская)" --to "Таганская (Кольцевая)"
```

Результат будет одним числом - временем в минутах

Посмотреть справку:

```bash
python -m main --help
python -m main path --help
python -m main time --help
```

Если одинаковое название встречается на разных линиях,
линия указывается в скобках. Например, `Курская (Кольцевая)` и
`Курская (Арбатско-Покровская)` считаются разными вершинами.
